# Security policy

Please report security issues privately through GitHub's **Security advisories** tab instead of opening a public issue.

This server is intentionally read-only. It must not log in, submit posts, solve CAPTCHAs, follow redirects outside an allowlisted source, or access private-network addresses. A source returning `401`, `403`, `429`, or a bot challenge is skipped and reported as a coverage warning.

Only public test data and systems you are authorized to access should be used when reproducing a report.
